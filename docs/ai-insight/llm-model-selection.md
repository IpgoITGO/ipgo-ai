# AI 인사이트 LLM 모델 선정

- 관련 Issue: #32
- 관련 요구사항: AI-02, BE-15, CM-04
- 측정 도구: `python -m insight.benchmark` (`insight/benchmark.py`), 검사기 `insight/validator.py` (#31)

## 결론

**`gpt-4o-mini`를 고릅니다.** 1차 측정에서 검사 통과율 100%(15/15)로 CM-04 1단계 관문 기준(90%)을 넘었습니다. `gpt-4o`는 46.7%(7/15)였고 건당 비용은 약 16배입니다.

| 측정 | 상태 | 입력 | 결과 |
|---|---|---|---|
| 1차 (10/30) | 완료 | 시험 prompt 고정본, 가짜 계산 결과 5종 | `gpt-4o-mini` 선정 |
| 2차 | 예정 | 운영 prompt 코드, 실제 계산 결과 31개 SKU | 선정 유지 여부 확인 |

1차 측정은 **규칙 준수율**(검사기 통과율)과 호출 비용 · 응답시간만 봅니다. 문장 내용이 맞는지와 셀러에게 도움이 되는지는 CM-04에서 봅니다.

### prompt 보강 과정

참조 구현 prompt(`prompt-2026.10.21-v0.4`)를 0002 이름으로 옮긴 판에서 시작해 두 번 고쳤습니다. 자세한 근거는 [insight_prompts.md](../../tests/fixtures/insight_prompts.md)와 [prompt 규칙](prompt-and-fallback.md) 3장(#14)에 있습니다.

| 단계 | 고정본 | `gpt-4o-mini` | `gpt-4o` |
|---|---|---|---|
| ① | 참조 prompt를 0002 이름으로만 옮김 (사례 6종) | 0% (0/18) | 0% (0/18) |
| ② | + "`[값]`은 참고값, 문장에는 `{{이름}}`" 지시, 배열 원소 하나에 문장 하나 | 55.6% (10/18) | 27.8% (5/18) |
| ③ | + 상태별 작성 예시 3개, 입고 불필요 사례 제외 | **100% (15/15)** | 46.7% (7/15) |

- ①에서는 두 모델 모두 자리 표시자 대신 목록의 `[값]`을 그대로 옮겨 썼습니다. 같은 모델에 참조 prompt를 그대로 보내면 통과했고, 이름만 바꿔도 실패했습니다.
- ②에서 정상 계열은 모두 통과했지만, 판단 보류 · 확인 필요는 정상 예시를 따라 하다 위험 방향 키를 쓰거나 한 원소에 두 문장을 넣었습니다.
- 입고 불필요(`NOT_NEEDED`)는 prompt 규칙 1장대로 LLM을 부르지 않으므로 ③에서 뺐습니다. ②에서는 "권장 입고량은 0개"처럼 숫자를 직접 써서 6건 모두 실패했습니다.

## 시간 제한 제안 (명세 7장)

LLM 호출 시간 제한은 **기본값 10초를 유지**하길 제안합니다. 1차 측정 최대 응답시간은 2,878ms로 약 3.5배 여유가 있고, `/engine/insight` 시간 제한 15초 안에 기본 문장 대체까지 들어갑니다. 2차 측정에서 p95가 5초를 넘으면 다시 봅니다.

## 한계와 다음 단계

- 표본이 작습니다. 15건 중 15건 통과는 95% 신뢰구간 하한이 약 78%입니다.
- 같은 5개 사례로 prompt를 고치고 측정해서, 처음 보는 입력에서는 더 낮을 수 있습니다.
- `gpt-4o-mini`는 상태별 예시 문장을 거의 그대로 따라 썼습니다. 기본 문장보다 나은 설명인지는 CM-04에서 판단합니다.
- 자리 표시자 이름만 보내는 판(`--no-values`)은 ③ 고정본으로 측정하지 않았습니다. 명세 7장 "실제 숫자 전송 여부"는 2차 측정에서 함께 봅니다.
- 2차 측정: 운영 prompt 코드와 실제 계산 결과 31개 SKU가 준비되면(#10, #18 이후) 같은 스크립트로 다시 재고 이 문서에 이어 씁니다.
