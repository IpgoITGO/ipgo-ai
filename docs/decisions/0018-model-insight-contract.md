# AI-01 모델 인사이트 계약 (#122)

2026-11-17. 사용자 승인 범위는 모델 인사이트 연결 보완과 오류 경로 검증 및 개발 배포다.
기존 개발 환경의 모델 설명 비활성 지시는 유지한다. 실제 엔진의 수량·위험 계산은 바꾸지 않는다.

- 모델 입력은 `method=LGBM19`, `riskStatus=NOT_COMPUTED`로 식별한다. 계산 결과의
  `riskStatus`는 기존처럼 null이며, 과거 표본 부족 상태로 치환하지 않는다.
- A/B의 기존 세 위험 상태와 prompt/version은 보존한다. 기존 요청의 method 생략도 수용한다.
- 모델에는 목표 재고 `target_stock`, 방식 표시 이름, 시나리오별 수량·잔여 재고를 사용한다.
  위험·표본·출고 범위·여유 배수·A/B 산식·대체 사유 키는 금지한다. 값은 Spring만 채운다.
- 표시 이름은 `예측 모델`, 미산출 문구는 `이 예측 방식에서는 품절 위험을 산출하지 않았습니다.`다.
  P90은 목표 재고 산출 입력이며 품절 방지 확률을 뜻하지 않는다.
- `IPGO_MODEL_INSIGHT_ENABLED` 기본 false. HTTP/SQS 공통 계산 경로와 인사이트 HTTP를
  모두 차단한다. 모델 미지원·입고 불필요 결과에는 입력/LLM 작업을 만들지 않는다.
- 명세 → Pydantic → Spring 순서로 구현한다. Spring 선반영 후 AI를 배포한다.
  응답 `InsightResponse`의 필드와 기존 계산 API의 위험 필드는 바꾸지 않는다.
- 복구는 모델 설명 스위치 OFF 및 이전 이미지다. 모델 weight·발주 수량·기존 데이터는 유지한다.
